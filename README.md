# 9. # Password Security Concepts

## 9.1 Password Recovery

Password recovery is the process of attempting to retrieve a password from a password-related representation, such as a hash or protected-file credential mechanism.

In an authorized cybersecurity environment, these techniques can be used to assess password strength and understand the risks associated with weak passwords.

---

## 9.2 Hashing

Hashing converts data into a fixed representation known as a hash or message digest.

In this practical, the PDF hash was used as the input for the password-recovery processes.

The exercise demonstrated how security tools can work with password-related representations without directly modifying the protected file.

## 9.3 Encryption vs Hashing
````markdown
Encryption and hashing are both important security techniques, but they serve different purposes.

### Encryption

```text
Plaintext
    |
    | Encryption
    v
Ciphertext
    |
    | Decryption using the correct key
    v
Plaintext
````

### Hashing

```text
Input
    |
    | Hash Function
    v
Hash / Digest
```

Encryption allows data to be converted back to its original form when the correct key is available. Hashing, on the other hand, is generally designed as a one-way process.

# 12. Recommendations

### 1. Use Strong Passwords

Use long, unique, and difficult-to-guess passwords to reduce the risk of password-based attacks.

### 2. Avoid Password Reuse

Avoid using the same password across multiple accounts, systems, or services.

### 3. Use a Password Manager

Password managers can help generate, store, and manage strong and unique passwords securely.

### 4. Enable Multi-Factor Authentication

Enable MFA where available to add an additional layer of protection beyond password-based authentication.

### 5. Protect Password Hashes

Password hashes and other credential-related data should be securely stored and protected from unauthorized access.
